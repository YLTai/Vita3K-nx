## 本版生产改动

### 逐次登记 sceGxmSetUniformDataF 的实际 memcpy

只在审核过的同步函数体内收窄根调用；转换 vector 为宿主私有存储，两个 Guest memcpy 写入点各自使用独立 HostOutputLease。平坦路径使用实际 offset/size；数组路径每次迭代使用实际目标和本次复制长度。开始前登记，结束/异常展开时解除，同值写入仍推进重叠版本，新登记 palette 立即看到活动输出。

**不按 componentCount 猜一个连续输出范围。** 既有数组循环的最终 chunk 可能超过请求剩余分量，并含向量对齐间隙；本版按实际 memcpy 追踪这些字节，不修改既有布局、转换或复制算法。既有窄类型标量展开/部分复制的源缓冲边界问题不是本轮修复范围；测试不把对齐正常案例的通过冒充这些路径已修复。未知外层调用仍保持未知。

### 五个确切只读叶函数

仅在 sceClibMemcmp、sceClibStrcmp、sceClibStrncmp、sceClibStrncasecmp、sceClibStrnlen 的实际实现中声明无 Guest 内存输出。它们只读取输入并返回值，不会调用 Guest 回调。不是按 NID/名字建立全局白名单，不包括 strncpy、strtoll、格式化输出、内核唤醒或异步 I/O；嵌套到未知外层时不能缩小外层契约。

### 输出来源版本化

output_leases 升为 version=2，sources 固定顺序为 generic、ATRAC9、AAC、MP3、GXM Uniform。保留旧 version=1 的四来源读取，不补造旧日志字段；未知版本、长度不符、来源和不等于 begins、未平衡结束或 authority=true 均拒绝。来源计数仍是写入区间，不是 GPU 完成或内容复用许可。
