## 本版实现

**不把这些整个 HLE 列为只读。** 在审核过的原生 condition-variable 等待期间，`NativeWaitLease` 暂时解除当前未知同步执行区间的全局 busy；进入时保留此前未知写入历史，退出时在执行任何后续代码之前恢复 unknown busy 并推进历史。嵌套 guard 不提前恢复或重复扣减，异常展开同样恢复。其他线程和导入仍分别跟踪。

接入内核等待、Switch 音频等待、vblank 等待，以及队列满／等待清空的位置。队列复制、通知、GXM 状态修改、音频复制和 vblank Guest 回调都在等待 guard 之外。已有明确输出范围的导入不被挂起：另一线程可能替等待者填写输出，这些范围整个期间仍 busy。

事件标志 wait/poll 在真实内核实现声明 outBits 与 timeout 输出。CB 入口只在回调之后的已审核尾部声明，并保留未知前缀版本。仍未知的调用不放行。原生等待不意味着此前启动的异步工作停止，本版明确不声明 async HLE/IPC 覆盖，也不授权 Hash 复用。

新增 `epoch_audit.range_contracts.native_waits`：park/resume/active 账本，以及每个根 NID 的等待次数、等待时的采样观察数。分析器核对账本，不把 parked sighting 当作写入覆盖率或运行时间。

## 一次运行，按样本自动延长

成功构建后只替换根目录 `Vita3K.nro`。进入目标场景，按一次 **L + R + Y**。仍运行 **A→B→B→A**；A 开放写表，B 持续观察已选纹理后备页，其他普通 Guest store 直达。

每段先稳定等待1秒，再测量至少6秒且至少50个有效间隔。样本不足时自动延长该段，测量预算最多12秒；达到预算仍不足就记录该段不足并继续，不要求重跑。正常回调下整轮约28～52秒，页表发布和帧停顿可能增加实际墙钟时间。没有渲染回调时不能仅凭计时器宣布完成。

Overlay：**OUTPUT / WAIT AUDIT**，阶段、实际进度、剩余预算、`Samples:n/50`，补样本时显示 `EXTENDING`，另有 `HLE/unknown/overlap/diff`。任何 DONE 后正常退出交一个完整 TraceLab ZIP。候选为零、黄色状态或反例都直接交报告；暂停/失焦仍显式中断，结束后退出菜单不破坏结果。

报告增加版本化 `sample_policy` 与各段是否达到上限。分析器分别输出 `evidence_eligible` 和 `comparison_eligible`：样本不足不抹掉有效阻塞证据，也不生成正式性能比较。旧日志继续按旧时间门槛分析，不能被新策略追认。A/B 共同包含页表、跨页与元数据成本，B/A 只衡量选定页拦截增量；没有写入时不代表测过持续写入成本。

## 验证及范围

本地实际元数据和 Queue 测试覆盖前后缀、嵌套/异常、其他写入者、等待者输出保持 busy、队列复制前恢复、4096 次并发等待区间。真实控制器/HUD/导出/分析器在100/130/1000ms合成回调下检查自动延长、预算不足、旧日志门槛和故意漏记写入的反例；新测试通过 ASan/UBSan。旧 epoch 与 HLE 范围回归也通过。

本地是稀疏源码，部分历史控制器配方由取得的固定源码还原；没有把这些主机执行说成完整仓库、Horizon、A64或GPU验证。CI 先验证全部固定 blob 配方、等待位置与主机回归，再进行目标编译、链接及打包。目标与设备结果分别确认。

**游戏仍使用完整参考 Hash；没有新增 RO、Hash 跳过、全局写慢路径或 GPU 等待。** 同步输出／原生等待的观察证据不是最终复用权威。GPU 完成、异步写入、真实资源生命周期与无扫描复用的净收益仍需集成，不能仅凭零候选失配启用。
